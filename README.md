Projeto - Urban.Grocers – Testes de API

1. Sobre o projeto: Projeto desenvolvido durante a formação em QA pela TripleTen, com foco nos testes de API da aplicação Urban.Grocers.

2. Objetivo: Validar os novos recursos de gerenciamento de produtos em kits e cálculo de entrega pelo serviço Order and Go.

3. Atividades realizadas

- Análise dos requisitos da API;
- Elaboração de checklist;
- Testes de requisições POST;
- Validação de parâmetros, dados e respostas da API;
- Testes positivos e negativos;
- Identificação e documentação de bugs no Jira.

4. Endpoints testados

- POST /api/v1/kits/{id}/products
- POST /order-and-go/v1/delivery

5. Ferramentas utilizadas

- Postman;
- Jira;
- Google Sheets.

6. Resultados

- Foram executados 63 testes
- Aprovados: 22;
- Reprovados: 41;
- Bugs documentados: 41.

7. Aprendizados: Prática em testes de API, análise de requisitos, validação de requisições e respostas HTTP, testes positivos e negativos e documentação de defeitos.
